# Emoji Python Codec (`emoji_python`) 🚀🍕

Полноценный пользовательский кодек для Python, позволяющий использовать любые эмодзи (включая составные) в качестве имен переменных, функций, методов и классов.

## 📦 Быстрая установка

```bash
pip install emoji-python
```


После установки вы можете запускать свои скрипты через встроенную CLI-команду:
```bash
emoji-run my_script.py
```
или через флаг модуля:
```bash
python -m emoji_python my_script.py
```

## 💻 Пример использования

В первой строке вашего `.py`-файла обязательно укажите `# coding: emoji_python`:

```python
# coding: emoji_python

# 1. Простые переменные-эмодзи
🚀 = 100
🔥 = 50

# 2. Составные эмодзи (поддерживаются ZWJ, флаги, модификаторы цвета кожи)
👨‍💻 = "Программист"
👍🏽 = "Отлично"
🇷🇺 = "Россия"
❤️ = "Сердце"

# 3. Функции с именами-эмодзи
def ➕(a, b):
    return a + b

# 4. Классы с именами-эмодзи
class 🐱:
    def __init__(self, имя):
        self.🏷️ = имя

    def 🗣️(self):
        return f"Мяу, меня зовут {self.🏷️}!"

# 5. Использование
кот = 🐱("Барсик")
print(кот.🗣️())
print(f"Сумма: {➕(🚀, 🔥)}")

# В строках и комментариях смайлики остаются нетронутыми:
print("Смайлики в строке: 🚀 🍕 🐱")
```

## ⚙️ Использование через `import` в коде

Если вы хотите запустить проект стандартной командой `python main.py`:

```python
# main.py
import emoji_python  # регистрирует кодек в системе
import my_emoji_code # любой ваш модуль с # coding: emoji_python
```

## 🛠 Как это устроено под капотом

1. **Токенизация**: Модуль лексически разбирает код с помощью `tokenize`. Все строки (`STRING`, `FSTRING_MIDDLE`), комментарии (`COMMENT`) и документация остаются абсолютно нетронутыми.
2. **Сборка составных эмодзи**: Регулярные выражения на базе Unicode UTS #51 парсят:
   - ZWJ-последовательности (`\u200d`, e.g. `👨‍💻`, `🐱‍👤`);
   - Модификаторы оттенка кожи Фитцпатрика (`👍🏽`);
   - Флаги стран из пар региональных индикаторов (`🇷🇺`);
   - Селекторы начертания (`\ufe0f`, `❤️`).
3. **Генерация идентификаторов**: Эмодзи транслируются в валидные Python-идентификаторы вида `_emoji_<hex1>_<hex2>_..._` (например, `👨‍💻` становится `_emoji_1f468_200d_1f4bb_`).
